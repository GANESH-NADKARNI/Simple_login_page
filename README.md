# Login Page

A simple and responsive login page built using **HTML and CSS**. This project provides a clean user interface for user authentication forms and serves as a beginner-friendly front-end web development project.

## Features

- Responsive design
- Modern and clean user interface
- Username/Email input field
- Password input field
- Login button
- Mobile-friendly layout
- Pure HTML and CSS implementation

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
login-page/
│
├── index.html
├── style.css
└── README.md
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/login-page.git](https://github.com/GANESH-NADKARNI/Simple_login_page.git)
```

2. Navigate to the project directory:

```bash
cd login-page
```

3. Open `index.html` in your preferred web browser.

## Usage

1. Open the login page in a browser.
2. Enter your username/email and password.
3. Click the **Login** button.

> Note: This is a front-end project only and does not include backend authentication or database integration.
